# Noggin

Raise a genius by teaching it. Every subject you study hatches a Nog, a little creature that only knows what you explain to it. Teach it clearly and it grows; explain vaguely and it gets hilariously confused, showing you exactly what you still don't understand.

## Workflow

- Work happens on feature branches (`feat/*`, `chore/*`) created from `staging`.
- Open a pull request into `staging`; after testing, `staging` is merged into `main`.
- Only the repository maintainer merges into `main`.
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/).
